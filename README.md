# Taiwan Travel

台湾の観光情報を紹介する架空のWebサイトです。

Webサイト制作演習の課題として制作し、その後、レスポンシブ対応やUIの調整、PHPによる共通パーツ化などのブラッシュアップを行いました。

## 概要

台湾の観光情報をテーマに、以下の3エリアを紹介する観光サイトです。

- 台北
- 台中
- 台南

トップページから各エリアのページへ移動でき、それぞれの地域ごとに観光地・グルメ・夜市・博物館などの情報を掲載しています。

スマートフォン・PCの両方で閲覧できるレスポンシブデザインに対応しています。
ブレイクポイントも以前より細かく設定しており、見やすさを追求しました。

## 使用技術

- HTML
- CSS
- JavaScript
- PHP
- jQuery
- Slick

## 主な実装内容

### レスポンシブデザイン

スマートフォンとPCでレイアウトが切り替わるように、メディアクエリを使用して実装しています。

### PHPによる共通パーツ化

ヘッダーとフッターをPHPファイルとして分離し、各ページから読み込む構成にしています。

ページごとのタイトル、ロゴ、説明文などは関数の引数として渡し、共通のHTMLを再利用できるようにしています。

### ハンバーガーメニュー

スマートフォン表示ではハンバーガーメニューを実装しています。

JavaScriptで以下の処理を行っています。

- メニューの開閉
- オーバーレイの表示
- メニュー表示中の背景スクロール制御

### 画像スライダー

トップページのGalleryでは、jQueryプラグイン「Slick」を使用した画像スライダーを実装しています。

PC版ではナビゲーションを表示し、スマートフォン版では画面サイズに合わせて表示方法を変更しています。

### モーダルウィンドウ

各地域ページでは、ボタンをクリックすると追加情報や画像を表示するモーダルウィンドウをJavaScriptで実装しています。

### ローディング画面

ページ表示時に、ロゴを使用したローディングアニメーションを表示しています。
